# Plugin Companion workspace

This repository contains the **My Enterprise Plugin** source package at [`my-enterprise-plugin/`](my-enterprise-plugin/README.md). The plugin provides local developer workflows and policy-checking utilities for Codex.

Start with the [plugin README](my-enterprise-plugin/README.md) for capabilities, setup, and limitations. For the ownership split between **enterprise**, **personal**, and **code repository** responsibilities, read [Ownership and deployment levels](my-enterprise-plugin/documentation/OWNERSHIP_AND_DEPLOYMENT_LEVELS.md).

The plugin source and safe fixtures live in the code repository. Personal Codex settings belong in the developer's home configuration. Authoritative enterprise policies, credentials, routing, telemetry, billing, and company data belong in systems managed by the organization. The files in this repository do not by themselves enforce those enterprise controls.
